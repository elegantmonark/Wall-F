# WALL-F Documentation

This folder contains the public report and process documents for WALL-F.

## Files

- `ELEC_FinalReport_TeamC1.pdf` - submitted final report.
- `Design_Proposal.pdf` - public copy of the design proposal with the original cover sheet removed.
- `Design_Journal_1.pdf` - early design journal public copy.
- `Design_Journal_2.pdf` - later design journal.

The proposal cover sheet was removed from the public copy because it contained student IDs. Two Design Journal 1 pages containing family-name figure captions were removed from the public copy. The final report has already been redacted for student numbers and family names.
